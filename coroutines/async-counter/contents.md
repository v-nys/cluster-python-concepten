Maak een coroutine `main` die drie taken opstart.

- De eerste van deze taken telt omhoog vanaf 0 en print elk berekend getal. Tussen elke print wacht ze 2 seconden.
- De tweede print om de drie seconden "ik ben taak 2".
- De derde print om de vijf seconden "ik ben taak 3".

Schrijf de code zodat de taken met elkaar *interleaven*.
