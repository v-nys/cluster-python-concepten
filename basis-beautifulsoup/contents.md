# BeautifulSoup
HTML (en code in verwante formaten) die je online terugvindt, volgt niet altijd netjes de regeltjes. Browsers proberen steeds voor een goede paginaweergave te zorgen, maar dat wil niet zeggen dat elke pagina die je ziet goed gestructureerd is. BeautifulSoup dient om "slechte" HTML zo goed mogelijk te structureren. Je kan het gebruiken als gewone formatter (dus om bijvoorbeeld ontbrekende closing tags toe te voegen,...), maar je kan er ook documenten mee analyseren. Je kan bijvoorbeeld, gegeven een HTML-document, alle afbeeldingen in dat document opvragen,...

Lees het onderdeeltje [Quick Start](https://www.crummy.com/software/BeautifulSoup/bs4/doc/) op deze pagina (dus tot de installatie). Installatie kan gewoon gebeuren in een virtual environment via `pip`.
