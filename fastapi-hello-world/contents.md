# Hello, World! in FastAPI
FastAPI is een web framework in Python dat gespecialiseerd is in het ontwikkelen van API's. Het volgt een aantal conventies en een consistente visie, waardoor je snel en makkelijk API's kan schrijven. Dit kan ook met andere web frameworks zoals Flask of Django, maar FastAPI maakt het proces zo gestroomlijnd mogelijk.

Bekijk het "Hello, World!" voorbeeld op [deze pagina](https://fastapi.tiangolo.com/tutorial/first-steps/). Je hoeft niet de volledige pagina te lezen, maar voer het voorbeeldprogramma een keer uit.

**Merk op**:

- Je bestand moet inderdaad `main.py` heten, je kan hier niet om het even wat kiezen.
- Als je je afvraagt waarom de functie `root` asynchroon is, zie [hier](https://fastapi.tiangolo.com/async/).
