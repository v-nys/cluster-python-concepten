# Requests
HTTP is het belangrijkste protocol voor browsers. Het is de taal waarin (onder andere) web content wordt opgehaald en verstuurd. [Requests](https://requests.readthedocs.io/en/latest/) is de makkelijkste manier om HTTP-verkeer te implementeren in Python. Je kan hiermee dus ook pagina's opvragen, formulieren invullen, enzovoort.

Lees alvast de officiële quickstart, onderdelen "Make a Request", "Passing Parameters in URLs" en "Response Content". Lees ook de titeltjes in de inhoudstafel, maar de inhoud daarvan mag je opzoeken wanneer je die nodig hebt.
