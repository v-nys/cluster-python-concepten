Ook deze opdracht veronderstelt dat je JSON server hebt gestart.

Schrijf een klein Python programma waarmee de user nieuwe posts en comments kan aanmaken en opslaan door de JSON server aan te spreken. Het programma start als volgt:

```text
Wat wil je doen?
1. Een nieuwe post aanmaken
2. Een comment toevoegen aan een bestaande post
```

Als de user ergens ID's gebruikt die niet bestaan, moet je programma dat op een duidelijke manier afhandelen.
