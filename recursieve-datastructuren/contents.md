Een recursieve datastructuur is een datastructuur (een type dat andere waarden "bevat") die in termen van zichzelf gedefinieerd is. Anders gezegd: een waarde die een waarde van hetzelfde type als onderdeel kan hebben.

Een Python dictionary is bijvoorbeeld een recursieve datastructuur, want deze kan (als values) "kleinere" dictionaries bevatten. Een getal is dat wat ons betreft niet, want we beschouwen het niet als iets dat bestaat uit onderdelen.
